> **提示：**这些 Prompt 在开启**全文解析**时效果最好，这样 AI 看到的是完整文章，而不是截取片段。



## 1）文章摘要

当你想要一份干净、可信、而且真的能指导行动的总结时，用这个。

```text
**角色设定：**
你是一位资深编辑与内容分析师。你的任务是将任何文本提炼成高度精炼的摘要，并确保准确性与对原文的忠实。

**指令：**
1. **分析：**深入理解文本的核心观点、论证与结论。
2. **忠实：**严格遵循原文内容。不要添加外部信息、推断或个人观点。保留所有关键信息。
3. **精炼与提炼：**摘要必须非常凝练。目标是用一个信息密度很高的段落，概括文本的本质。优先信息密度，而不是铺陈描述。
4. **语言：**自动检测输入语言；输出必须使用高质量、流畅的 {{language}}。
5. **直接输出：**直接给出结果，不要写任何开场白、问候语或解释。
```



## 2）三层摘要（快速扫读）

当你既想快速浏览，又不想错过别人常忽略的关键信息时，用这个。

```text
请用三层结构把文章总结成 {{language}}。

规则：
- 只使用文章内容。
- 三层之间不要重复。
- 如果你不确定，就写“文章未提及”。

输出：
- TL;DR（1–2 句话）
- 关键要点（5 个要点，项目符号）
- 容易被忽略的细节（3 个要点：注意事项/前提假设/限制条件/边界情况/数字信息）
```



## 3）关键词 + 主题提取（用于打标签和延伸阅读）

适合做整理、后续搜索，以及搭建“延伸阅读清单”。

```text
从文章中提取最重要的关键词/主题。

规则：
- 输出为 {{language}}。
- 优先抽取概念、实体和反复出现的主题（不要泛泛的通用词）。
- 专有名词（人物/组织/产品名）在合适情况下保留原文写法。
- 不要重复。

输出（Markdown）：
- 关键词（10 个）
- 核心主题（3 个，范围比关键词更大）
```



## 4）社交媒体转发生成器（分享但不“模板味”）

适合你想快速发帖，但又希望保留自己的表达风格时使用。

```text
根据文章撰写社交媒体帖子。

规则：
- 输出为 {{language}}。
- 必须忠实反映文章内容（不要编造结论或数据）。
- 表达要有力、自然，不要太“营销腔”。
- 包含 2–3 个相关话题标签（hashtags）。
- 如果文章里有关键数字或关键结论，请带上。
```



## 5）Hashtag + 话题角度生成器（提高可发现性）

可以单独用，也可以和上面的社交帖子 Prompt 搭配使用。

```text
基于文章生成 hashtags 和发帖角度。

规则：
- 输出为 {{language}}。
- Hashtag 要简短、常见、贴合主题。
- 避免过长的 hashtag；避免重复。

输出（Markdown）：
- Hashtags（5–8 个，包含 # 前缀）
- 话题角度（3 个要点：面向不同受众，用不同方式表达同一篇文章的价值）
```



## 附加：一个简单的“Prompt 串联”工作流

如果你想要一条顺滑的 **阅读 → 处理 → 分享** 流程，可以这样串：

- 关键词 + 主题提取 → Hashtag + 话题角度生成 → 社交媒体转发生成
